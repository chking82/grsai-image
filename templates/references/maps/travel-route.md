# Travel Route Map — 旅行路线图

## 适用场景
旅行行程规划、游记配图、旅游产品宣传、个人旅行回顾。用于可视化展示旅行路线和途径城市。

## Prompt 结构
```
An illustrated travel route map showing a {trip type — multi-city journey/road trip/hiking trail/cruise route} from {starting point} to {ending point} through {key stops}. The map features {style — vintage travel poster/modern flat design/hand-drawn watercolor}. {Route line style — dashed solid/curved with icons}. {Landmark illustrations along the route}. Travel route map, itinerary visualization, journey path illustration --ar 16:9
```

## 注意事项
- **路线清晰**：路线线要粗而明显，方向箭头标示旅行方向
- **地标代表**：每个城市用标志性建筑/特色图标代表，不要只用文字
- **距离/时间**：标注城市之间的交通方式和大致时间，帮助规划
- **地形暗示**：山脉、河流、海洋等地形要素帮助建立空间感
- **风格统一**：复古、扁平、手绘——整张地图保持一种风格
- **信息密度**：不要标注每个小镇，只标注重要停靠点
- **方向指引**：指南针或北方箭头是必须的
- **可打印性**：旅行地图常被打印携带，确保在小尺寸下文字可读
