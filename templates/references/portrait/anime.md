# anime — 动漫头像

## 适用场景
日系动漫、二次元、ACG 头像。

## Prompt 结构
```
An anime style portrait of [age]-year-old [gender] [ethnicity] [role], [detailed hair description], [detailed eye description], [expression], [attire], [pose and framing], [background], [quality suffix], [aspect ratio]
```

## 质量后缀
```
anime style portrait, Japanese animation style, cel shading technique, vibrant colors, expressive large eyes, detailed hair rendering
```

## 注意事项
- 动漫眼睛画法：多层虹膜、大高光点、反射光
- 发型细节丰富：分缕、高光、动态感
- 色彩饱和度高，明亮鲜艳
- 表情要鲜明传达角色性格
- 赛璐璐上色（cel shading）风格
- 清晰锐利的线条
