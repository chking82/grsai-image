# Gradient Background

## 适用场景

抽象渐变背景：流体渐变、mesh gradient、UI 设计背景、PPT 背景、网站 Hero Section 背景等现代抽象渐变场景。

## Prompt 结构

```
[渐变类型/形态] + [色彩组合] + [流动感/质感] + [质量后缀] + [比例参数]
```

The composition is smooth and uniform without harsh edges or distinct boundaries, perfect for text overlay and UI elements. ## 质量后缀

```
abstract gradient background, modern gradient design, fluid shapes, mesh gradient texture
```

可选增强：`seamless color blending, soft diffused lighting, contemporary UI aesthetic, dark mode aesthetic, subtle noise texture, pastel color palette, watercolor-like transparency`

## 注意事项

- **平滑过渡**：使用 "seamless", "soft feathered edges", "smooth diagonal waves" 确保渐变过渡自然，无生硬边界
- **现代感**：mesh gradient 是当前设计趋势，使用 "organic shapes"、"liquid-like"、"undulating waves" 增强流动感
- **不抢文字风头**：渐变背景的目的在于衬托文字和内容，避免使用过于饱和或对比强烈的配色，强调 "even tonal distribution" 和 "suitable for text overlay"
- **暗色/亮色版本**：提供 dark mode 和 light mode 两套方案以适应不同设计需求
