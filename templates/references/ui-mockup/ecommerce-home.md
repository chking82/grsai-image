# ecommerce-home — 电商首页

## 适用场景
淘宝/京东类 App 首页、移动电商购物平台主界面、促销活动落地页。

## Prompt 结构
```
A mobile e-commerce home screen UI mockup, [layout description: header + search bar + banner carousel + category grid + product feed], [color scheme], [style notes], [quality suffix], [aspect ratio]
```

## 注意事项
- **移动端比例**：使用 9:16 竖屏比例，模拟手机屏幕
- **导航栏**：顶部通常包含搜索框、消息通知、购物车图标
- **商品卡片**：展示产品图、名称、价格（突出显示），可选原价划线
- **购物车**：底部或右上角的购物车图标，带数量徽章
- **颜色**：电商常用红色/橙色作为促销主色调，传递紧迫感
- **层级**：Banner > 分类 > 推荐商品的视觉层级要清晰
- **避免文字过多**：UI mockup 中避免生成大量可读文字，聚焦布局结构
