# 模板：故事板/漫画分镜

## 适用场景
用户要求生成漫画分镜、故事板、四格漫画、绘本插图、连环画、连续画面等。

## 需求收集清单

| 字段 | 类型 | 必填 | 选项/说明 |
|------|------|------|----------|
| story_theme | text | ✅ | 故事主题/剧情 |
| sub_type | select | ✅ | 见下方子模板类型 |
| panel_count | select | ❌ | 四格/六格/三格/全屏连续画面 |
| style | select | ❌ | 日式漫画/美式漫画/手绘/简约/水彩 |
| character | text | ❌ | 主要角色描述 |
| mood | select | ❌ | 搞笑/感人/悬疑/温馨/热血 |

## 子模板类型（references/storyboard/）

| 子模板 | 文件 | 关键词 | 示例场景 |
|--------|------|--------|---------|
| 四格漫画 | `four-panel.md` | 四格、搞笑、日常 | 社交媒体、日常分享 |
| 故事板 | `storyboard.md` | 分镜、场景、流程 | 视频脚本、广告分镜 |
| 绘本插图 | `picture-book.md` | 绘本、儿童、温馨 | 儿童绘本、故事书 |
| 漫画分镜 | `comic-spread.md` | 漫画、跨页、动态 | 漫画连载、游戏剧情 |
| 角色关系图 | `character-relations.md` | 角色、关系、连接 | 游戏角色设定 |
| 料理/教程漫画 | `recipe.md` | 步骤、教程、流程 | 烹饪步骤、DIY 教程 |

## 推荐参数

- model: gpt-image-2-vip
- imageSize: 2048x2048（2K 1:1）/ 3840x2160（4K 16:9 故事板）
