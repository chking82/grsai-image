# pixel — 像素头像

## 适用场景
复古游戏、极客、8-bit 像素风格。

## Prompt 结构
```
A pixel art portrait of [subject description], [physical features], [attire], [pose and framing], [color palette], crisp pixel blocks, [quality suffix], [aspect ratio]
```

## 示例

### 示例 1
**用户输入：** 游戏玩家像素头像
**Prompt：**
```
A pixel art portrait of a young East Asian male gamer, blocky short black hair made of distinct pixel squares, large expressive pixelated dark eyes with white pixel highlights, pixelated smile, wearing a red pixel cap worn backwards and a green pixel hoodie, square frame, chest-up view, limited color palette of about 16 colors, crisp individual pixel blocks clearly visible, retro game aesthetic with intentional pixelation, no anti-aliasing, dark navy blue solid background, pixel art portrait, 16-bit style, retro game aesthetic, crisp pixel blocks, limited color palette, 32x32 pixel resolution feel --ar 1:1
```

### 示例 2
**用户输入：** 极客 8-bit 头像
**Prompt：**
```
A pixel art portrait of an East Asian male developer wearing round pixelated glasses, blocky neat black hair in 8-bit style, simple but expressive pixel eyes with single white pixel highlights, pixelated neutral expression, wearing a gray pixel t-shirt with a small pixel heart design on chest, square frame, chest-up view, restricted 8-bit color palette with about 8 distinct colors, very crisp visible pixel grid, retro computer game style from 1980s era, light gray solid background, pixel art portrait, 8-bit style, retro game aesthetic, crisp pixel blocks, limited color palette, NES-era graphics feel --ar 1:1
```

### 示例 3
**用户输入：** 像素风女设计师
**Prompt：**
```
A pixel art portrait of an East Asian female designer, blocky shoulder-length pink hair with distinct pixel strands, large cute pixelated eyes with white highlights, pixelated cheerful smile with small blush pixel marks on cheeks, wearing a yellow pixel beret and a purple pixel dress, square frame, chest-up view, vibrant but limited pixel color palette with about 20 colors, crisp individual pixel blocks, 16-bit retro game style with slightly more detail than 8-bit, soft lavender solid background, pixel art portrait, 16-bit style, retro game aesthetic, crisp pixel blocks, limited color palette --ar 1:1
```

## 质量后缀
```
pixel art portrait, 16-bit style, retro game aesthetic, crisp pixel blocks, limited color palette
```

## 注意事项
- 像素级精度：每个像素块都要清晰可见
- 有限色板：8-bit 约 8 色，16-bit 约 16-20 色
- 无抗锯齿（no anti-aliasing），保持像素锐利
- 复古感：参考 NES、SNES 时代风格
- 清晰轮廓，简化细节
- 方形画幅最适合像素头像
