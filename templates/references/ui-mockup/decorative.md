# decorative — 装饰元素

## 适用场景
UI 分隔线、边框、背景装饰图案、页面点缀元素、空状态插画。

## Prompt 结构
```
[Type of decorative element], [style description], [color palette], [usage context], [quality suffix], [aspect ratio]
```

## 质量后缀
```
UI decorative elements, interface ornaments, design accents, subtle and elegant, professional design quality, doesn't overpower content
```

## 注意事项
- **不抢主要内容风头**：装饰元素应该微妙精致，用低饱和色或低透明度
- **微妙精致**：使用浅灰色、淡色调、低透明度（10-30%）
- **统一语言**：同一页面的装饰元素风格应一致，不要混用多种风格
- **功能性**：分割线用于内容分隔，边框用于区域界定，背景用于层次
- **空状态**：空状态插画要友好积极，减少用户的挫折感
- **渐变趋势**：Mesh gradient 和柔和渐变是当下主流设计趋势
- **尺寸适配**：装饰元素应能灵活适配不同屏幕尺寸
