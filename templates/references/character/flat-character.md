# 扁平角色

## 适用场景
SaaS 产品引导页、落地页插画、营销材料角色、移动端 UI 插画。适合现代互联网产品的扁平化视觉风格。

## Prompt 结构
```
A flat illustration of {character description}, designed in a {style — modern/corporate/playful} flat illustration style. The character has {body proportions and features} with {skin tone/hair} and is wearing {clothing description}. The character is {action/pose — sitting, standing, holding} with a {facial expression} expression. {Scene/context description — desk, laptop, abstract shapes}. Color palette: {color scheme}. Clean geometric shapes, no outlines, limited color palette. Set on a {background} background. Flat character design, modern illustration style, corporate character illustration, clean vector shapes.
```

```

The character is sitting in a relaxed posture, one hand on the laptop keyboard and the other holding a steaming coffee mug, with a focused yet content expression — slight smile, eyes looking at the screen. The desk has a small potted succulent, a stack of colorful books, and the laptop screen shows abstract code blocks in a simplified UI. Behind the character, a large window reveals a simplified city skyline with geometric building silhouettes in soft blue tones. Color palette: warm neutrals (beige desk, grey hoodie) with accent colors of teal (laptop screen), coral (coffee mug), and sage green (plant). Clean geometric shapes, no outlines, limited color palette of 6-8 colors. Set on a soft cream background with abstract geometric floating shapes in the periphery. Flat character design, modern illustration style, corporate character illustration, clean vector shapes.
```

## 质量后缀
```
flat character design, modern illustration style, corporate character illustration, clean vector shapes
```

## 注意事项
- 扁平风格的核心是：无描边（no outlines）、几何形体、有限色盘
- 人物比例可以简化——不需要真实比例，头身比 1:3 到 1:5 都很常见
- 手部通常简化处理（不画手指细节）
- 颜色要鲜明但数量要少（6-8 色为宜），保持视觉统一
- 适合 landing page、onboarding、feature introduction 等场景
- 背景可以加抽象几何装饰元素增加层次感
- 输出分辨率建议 2048x1152（16:9 适合网页展示）
