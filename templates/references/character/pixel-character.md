# 像素角色

## 适用场景
像素风游戏角色设计、复古风格插画、8-bit/16-bit 风格 UI 元素、怀旧主题营销素材。适合独立游戏、复古品牌、NFT 头像等场景。

## Prompt 结构
```
A pixel art {character type} of {character description}, rendered in a {bit style — 8-bit/16-bit/32-bit} retro game sprite style. The character features {physical description} with {color details}. The character is {pose/action — standing, running, idle animation frame} with {facial expression/details visible at pixel level}. {Weapon/accessory description if applicable}. Limited color palette with {number} colors, sharp pixel edges with no anti-aliasing, {palette technique — dithering/solid blocks}. Set on a {background} background with {environmental elements}. Pixel art character, 16-bit style game character, retro game sprite, crisp pixel blocks.
```

## 注意事项
- 像素艺术的核心是清晰的像素边界——不能有抗锯齿
- 色盘要有限（8-bit 通常 16 色以内，16-bit 可以稍多）
- 抖动（dithering）是重要的像素着色技巧，可以提及
- 角色比例要适合像素分辨率——脸部细节要足够大才能识别
- 适合游戏 sprite sheet 制作、NFT 头像系列、复古风品牌
- 输出建议放大 4-8 倍显示（原始像素尺寸通常很小）
- 透明背景更实用（方便合成到游戏场景中）
