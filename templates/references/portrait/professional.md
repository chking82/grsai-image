# professional — 职业形象照

## 适用场景
LinkedIn 头像、简历照、商务社交平台专业头像。

## Prompt 结构
```
A professional headshot portrait of [age]-year-old [gender] [ethnicity] [profession], [hair style], [eye color] eyes, [facial expression], wearing [attire], chest-up framing, clean studio lighting, soft background, [quality suffix], [aspect ratio]
```

## 质量后缀
```
professional headshot photography, corporate portrait, business professional, clean studio lighting, natural skin tone, shallow depth of field, 85mm lens look, high resolution
```

## 注意事项
- 保持自然肤色，避免过度修饰或磨皮
- 胸部以上裁剪（chest-up framing）
- 专业布光：三点布光或柔和单光源
- 背景简洁：纯色或微渐变
- 眼神需有光点（catchlight），显得有神
- 着装得体，符合行业惯例
