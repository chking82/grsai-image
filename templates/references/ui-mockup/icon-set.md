# icon-set — 功能图标集

## 适用场景
App 图标库、设计系统图标、导航图标、功能操作图标集合。

## Prompt 结构
```
A set of [style] UI icons, [number] icons in a [layout: grid / showcase], [icon type description], [color scheme], [grid notes], [quality suffix], [aspect ratio]
```

## 质量后缀
```
icon set design, consistent icon family, modern UI icons, professional icon design, design system quality, uniform visual weight
```

## 注意事项
- **统一线宽**：线性图标必须保持相同的描边粗细（通常 1.5px 或 2px）
- **网格对齐**：所有图标基于同一网格（常用 24x24），内边距一致
- **可识别性**：图标语义清晰，即使小尺寸也能辨认
- **风格统一**：要么全部线性，要么全部填充，不可混用
- **圆角处理**：统一圆角半径，保持柔和一致的视觉感受
- **配色方案**：单色或双色为主，避免过多颜色破坏一致性
- **数量展示**：展示 12-20 个图标最能体现系统性
