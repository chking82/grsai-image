# Texture Wallpaper

## 适用场景

纯色/纹理壁纸：纸纹、噪点、布纹、混凝土、大理石等微妙纹理背景，适用于设计作品的底图、PPT 背景、网站背景、产品展示背景等需要质感但不抢风头的场景。

## Prompt 结构

```
[纹理类型/材质] + [色彩基调] + [微妙程度] + [质量后缀] + [比例参数]
```

## 注意事项

- **微妙纹理**：纹理壁纸的关键在于 "subtle"、"understated"、"visible upon close inspection"——纹理应该是近看才能发现的细节，而非远距离就能察觉的图案
- **不喧宾夺主**：始终强调 "without competing with foreground content"、"versatile design backdrop"，确保纹理服务于内容而非抢夺注意力
- **设计背景**：纹理壁纸的核心价值是为设计作品增添质感和温度，使用 "premium"、"refined"、"warmth and character" 描述其增值效果
- **色彩中性**：纹理壁纸通常使用中性色（off-white、gray、charcoal、ivory），确保与各种前景内容的兼容性
