# Hand-Drawn Illustration — 手绘草图

## 适用场景
- 创意构思 / Brainstorming 配图
- 笔记类应用界面配图
- 设计过程展示
- 轻松随性风格配图
- 教程/说明书插图

## Prompt 结构
```
[主体描述], hand-drawn illustration, sketchy lines, organic feel, ink and pencil style, [笔触细节], [纸张效果], --ar 16:9
```

## 质量后缀
```
hand-drawn illustration, sketchy lines, organic feel, ink and pencil style, rough edges, crosshatching, notebook paper texture
```

## 注意事项
- 保留手绘痕迹：线条不规则、有轻有重
- 草稿感是关键，不要追求完美
- 可加入标注线、箭头、手写文字
- 纸张纹理应可见（牛皮纸/笔记本纸）
- 墨水风格可用钢笔/针管笔质感
- 线条可以有交叉涂线（crosshatching）增加深度
