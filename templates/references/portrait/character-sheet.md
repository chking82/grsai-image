# character-sheet — 角色设定表

## 适用场景
三视图、多视角、角色开发文档。

## Prompt 结构
```
A character design sheet showing [subject description] from multiple angles, [physical features], [attire details], front view side view back view, [background], clean layout, [quality suffix], [aspect ratio]
```

## 质量后缀
```
character design sheet, three-view reference, front side back poses, character turnaround, concept art reference
```

## 注意事项
- 统一角色：所有视角必须保持相同配色和比例
- 多个角度：至少正面、侧面、背面三视图
- 干净布局：白色或浅灰背景，清晰排列
- 可加入色板、表情变化、配件标注等参考元素
- 适合角色开发、IP 设计、游戏美术参考使用
