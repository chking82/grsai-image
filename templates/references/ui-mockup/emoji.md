# emoji — 表情包

## 适用场景
聊天表情包、社交平台贴纸、IM 应用自定义表情、品牌 IP 表情。

## Prompt 结构
```
A set of [style] emoji / sticker designs, [number] expressions, [character/subject description], [color palette], [layout], [quality suffix], [aspect ratio]
```

## 注意事项
- **统一风格**：同一套表情必须保持一致的角色设计、线条粗细、配色
- **表情丰富**：覆盖喜、怒、哀、乐、惊讶、害羞、思考等常见情绪
- **适合小尺寸**：表情通常在 32-64px 显示，细节不能过于复杂
- **辨识度**：表情差异明显，即使缩小也能区分
- **角色一致性**：如果使用 IP 角色，身体比例、颜色方案必须统一
- **背景处理**：通常用纯白或透明背景，方便在聊天中叠加
- **轮廓处理**：带粗轮廓线的表情在小尺寸下更易辨认
