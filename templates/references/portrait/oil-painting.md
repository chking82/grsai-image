# oil-painting — 油画肖像

## 适用场景
古典油画肖像、艺术风格、厚重质感。

## Prompt 结构
```
An oil painting portrait of [subject description], [physical features], [attire], [pose], [lighting style], [background], visible brushstrokes, canvas texture, classical painting technique, [quality suffix], [aspect ratio]
```

## 质量后缀
```
oil painting portrait, classical portrait technique, rich brushstrokes, Rembrandt lighting, museum quality, old master style, impasto texture
```

## 注意事项
- 画布质感要可见（canvas texture）
- 笔触要明显（visible brushstrokes, impasto）
- 古典光线：Rembrandt 光、chiaroscuro
- 深色或温暖色调背景
- 色彩层次丰富，有 glazing（罩染）效果
- 整体呈现博物馆级艺术品感
