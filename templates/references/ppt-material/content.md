# Content Background — 内容页背景

## 适用场景
- 正文内容页背景
- 会议记录/纪要页面
- 培训课件文字页
- 说明文档展示页
- 图文混排内容页

## Prompt 结构
```
[微妙的纹理/图案], [柔和色彩方案], [干净底色], subtle presentation background, content slide backdrop, text-friendly design, 4k, ultra detailed, high resolution --ar 16:9
```

## 注意事项
- **不抢文字风头**：这是最重要的原则——背景必须退居幕后，任何可见纹理的对比度都应极低（建议 < 10%）
- **微妙纹理**：可以使用极淡的网格、点阵、水波纹、渐变等，但必须若隐若现，不能成为视觉焦点
- **高对比度保证可读性**：底色应足够浅（或足够深），确保正文文字（黑色或白色）有 ≥ 4.5:1 的对比度比
- **均匀亮度**：避免大面积的明暗变化，否则会影响不同位置文字的阅读体验
- **留白充足**：内容页应预留至少 60% 的干净区域供文字使用
- **一致性**：同一套 PPT 中所有内容页背景风格应保持统一
