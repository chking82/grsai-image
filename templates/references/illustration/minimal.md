# Minimal Line Illustration — 极简线条

## 适用场景
- 商务配图 / 企业官网
- 图标背景 / Icon backdrop
- SaaS 产品页面
- 专业报告配图
- 现代品牌视觉

## Prompt 结构
```
[主体描述], minimal line illustration, clean strokes, negative space, simple geometric shapes, [配色方案], [构图], --ar 16:9
```

## 注意事项
- 极简线条：所有造型用最少的线条表达
- 大量留白：负空间是构图的重要部分
- 单色或少色：通常黑白 + 1-2 种强调色
- 避免填充大面积色块，以描边为主
- 人物和物体高度简化（火柴人级别细节）
- 线条粗细统一，保持干净利落
