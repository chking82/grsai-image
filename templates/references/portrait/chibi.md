# chibi — Q版头像

## 适用场景
二次元、萌系、大头小身、可爱风格。

## Prompt 结构
```
A chibi style avatar of [subject description], [physical features with exaggerated cute elements], [attire], [pose], [color scheme], [quality suffix], [aspect ratio]
```

## 质量后缀
```
chibi style avatar, cute proportions, kawaii character design, big eyes small body, simplified facial features
```

## 注意事项
- 大头小身比例是核心：头部占身体 1/2 到 1/3
- 眼睛要非常大，占面部 1/3 以上，带多个高光点
- 表情简单可爱：微笑、w 形嘴、脸红
- 柔和的粉彩色配色方案
- 线条简洁，不需要复杂阴影
- 可加入小装饰元素（星星、爱心等）增加萌感
