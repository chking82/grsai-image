# Cartoon Style — 卡通风格

## 适用场景
- 儿童内容配图
- 教育产品配图
- 轻松幽默配图
- 社交媒体配图
- 品牌吉祥物设计

## Prompt 结构
```
[主体描述], cartoon style illustration, cute colorful characters, animated aesthetic, bold outlines, [色彩方案], [表情/动作], --ar 16:9
```

## 质量后缀
```
cartoon style illustration, cute colorful characters, animated aesthetic, bold outlines, expressive faces, vibrant flat colors, Disney-inspired
```

## 注意事项
- 可爱造型：大头、大眼、圆润轮廓
- 明亮色彩：高饱和度、对比鲜明
- 简单表情：夸张的五官表现情绪
- 粗描边（bold outlines）增强卡通感
- 避免复杂阴影，使用简单的色块阴影
- 角色比例可以夸张化（Q版 2-3 头身）
