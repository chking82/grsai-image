# Portrait Retouch — 人像修饰

## 适用场景
人像美颜修饰、肤色调整、光影优化、证件照美化、社交媒体人像精修。用于提升人像照片的专业度和美观度。

```

Portrait retouching, beauty enhancement, professional portrait editing --ar 4:5
```

## 注意事项
- **保留皮肤纹理**：过度磨皮会失去真实感——保留毛孔和细微纹理是关键
- **眼神光必备**：没有眼神光的人像是死的——至少一个小的高光点
- **肤色均匀**：人脸不同区域肤色不同（额头偏黄、脸颊偏红）要自然过渡
- **修饰适度**：证件照修饰要保守，时尚照可以激进——根据用途决定程度
- **牙齿美白**：适度美白即可，纯白牙齿看起来假——保留自然的微黄色调
- **头发细节**：飞起的碎发要整理，但完全光滑的头发看起来像假发
- **身形比例**：可以微调双下巴和脸部轮廓，但大幅度改变会导致失真
- **光影优化**：人像修饰不只是皮肤——消除难看的阴影比磨皮更重要
