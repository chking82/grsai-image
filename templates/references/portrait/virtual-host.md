# virtual-host — 虚拟主播

## 适用场景
VTuber、直播虚拟形象、二次元虚拟主播。

## Prompt 结构
```
A virtual youtuber character design portrait of [subject description], [detailed hair description with anime styling], [eye description], [expression], [detailed costume design], [pose], [background], [quality suffix], [aspect ratio]
```

## 质量后缀
```
virtual youtuber character design, VTuber avatar, anime streaming personality, detailed costume design, digital avatar
```

## 注意事项
- 直播镜头感：表情要丰富、有活力，适合屏幕展示
- 角色服装细节要丰富：配饰、层次、材质感
- 发型层次分明，动漫风格光泽感
- 表情丰富：VTuber 通常需要多种表情变化
- 背景可以加入直播相关元素（灯光、特效等）
- 整体色彩鲜明，在直播画面中引人注目
