# City Map — 手绘城市地图

## 适用场景
旅游指南地图、城市宣传海报、文创产品（明信片、帆布袋）、教育用途。用插画风格展示城市特色。

## Prompt 结构
```
A hand-drawn illustrated city map of {city name}, showing {key areas/landmarks}. The map uses {style — watercolor illustration/cute cartoon style/detailed pen and ink}. {Notable features — illustrated buildings/parks/waterways/transportation}. {Color palette and overall mood}. Hand-drawn city map illustration, tourist city guide map, illustrated urban map --ar 16:9
```

## 注意事项
- **地标优先**：手绘城市地图的核心是地标建筑，地图精度可以牺牲但地标必须可识别
- **河流定位**：大多数城市依水而建，河流是最好的定位参照
- **区域色彩**：不同区域用不同色调区分——历史区用暖色，商业区用亮色，公园用绿色
- **文化细节**：加入当地特色小元素（北京的自行车、上海的游船、伦敦的红色电话亭）
- **比例灵活**：市中心区域可以放大，郊区可以缩小，不必严格等比
- **文字双语**：旅游地图建议中英文双语标注
- **风格匹配**：手绘风格要与城市气质匹配——北京用水墨，伦敦用英式插画，东京用漫画风
- **实用信息**：可以标注地铁线路、最佳拍照点、推荐游览顺序等实用信息
