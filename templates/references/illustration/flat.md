# Flat Illustration — 扁平插画

## 适用场景
- App 引导页 / Onboarding 配图
- 营销落地页插画
- 产品功能说明图
- 数据可视化配图
- 企业品牌视觉

```

```

## 注意事项
- 使用简洁几何形状，避免复杂细节
- 不使用渐变效果，保持纯色块
- 色彩对比要鲜明，但数量控制在 3-5 种
- 人物造型简化为几何比例（大头、细四肢）
- 善用负空间（留白）保持画面清爽
- 避免阴影、纹理等写实效果
