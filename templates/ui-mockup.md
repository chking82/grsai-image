# 模板：UI/界面

## 适用场景
用户要求生成 UI 界面设计稿、App 界面、网页 Mockup、图标、UI 组件、界面元素等。

## 需求收集清单

| 字段 | 类型 | 必填 | 选项/说明 |
|------|------|------|----------|
| platform | select | ✅ | 移动端/桌面 Web/iOS/Android/桌面 App |
| sub_type | select | ✅ | 见下方子模板分类 |
| style | select | ❌ | 现代/极简/暗黑/玻璃拟态/新拟态/扁平 |
| color_scheme | text | ❌ | 配色方案或品牌色 |
| components | text | ❌ | 需要包含的界面组件 |
