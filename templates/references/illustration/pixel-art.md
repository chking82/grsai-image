# Pixel Art — 像素艺术

## 适用场景
- 游戏素材 / Game assets
- 复古品牌视觉
- 怀旧主题配图
- NFT/加密艺术
- 科技复古（Retrofuturism）配图

## Prompt 结构
```
[主体描述], pixel art illustration, 16-bit style, retro game aesthetic, crisp pixel blocks, [色彩方案], [渲染细节], --ar 16:9
```

## 质量后缀

pixel art illustration, 16-bit style, retro game aesthetic, crisp pixel blocks, limited color palette, anti-aliasing, sprite sheet quality

## 注意事项
- 像素级精度：每个像素都应是清晰的方块
- 色板有限：16-bit 风格通常 32-256 色
- 网格对齐，不使用抗锯齿（除非特别指定）
- 角色/物体比例要符合像素网格
- 阴影和高光用色阶跳跃，不用渐变
- 可参考经典游戏（塞尔达、星露谷、空洞骑士）的像素风格
