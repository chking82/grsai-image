# Healing Style Wallpaper

## 适用场景

治愈系壁纸：柔和、温暖、让人感到平静和舒适的壁纸，适用于个人桌面、冥想应用背景、心理健康类产品设计等。

## Prompt 结构

```
[治愈意象/场景] + [柔和光效/色彩] + [平静氛围] + [质量后缀] + [比例参数]
```

## 注意事项

- **低饱和度**：治愈系的核心是 "muted pastels"、"low saturation"、"soft tones"，避免任何强烈或刺眼的色彩
- **柔和光线**：使用 "gentle morning light"、"soft focus"、"warm glow"、"no harsh contrasts" 营造温柔的光感
- **平静感**：构图简单、元素少、留白多 — "minimalist"、"simple and unhurried"、"breathing room" 是关键词
- **手绘质感**：加入 "watercolor"、"paper texture"、"hand-drawn"、"storybook" 增强温暖和亲切感
