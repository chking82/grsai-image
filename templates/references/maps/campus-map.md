# Campus Map — 校园地图

## 适用场景
大学校园导览图、新生入学指南、校园开放日宣传、学校文创产品。用插画风格展示校园布局。

## Prompt 结构
```
An illustrated campus map of {university/school name}, showing {key buildings and facilities}. The map uses {style — watercolor illustration/clean vector/cute cartoon}. {Buildings illustrated with architectural detail}. {Landscape features — trees/lawns/water features}. {Path and road network}. Campus map illustration, university guide map, school facility layout illustration --ar 16:9
```

## 注意事项
- **功能分区**：教学区、生活区、运动区要清晰区分，不同区域用不同色调
- **地标建筑**：图书馆通常是校园最标志性的建筑，应该最突出
- **道路网络**：主干道和支路要区分——主干道用粗线，小径用细线或虚线
- **绿色空间**：校园的绿色环境是重要特色——树木、草坪、花园要充分体现
- **生活细节**：加入自行车停放区、自动贩卖机、公告栏等生活细节增加真实感
- **新生友好**：标注新生最常去的地方（食堂、宿舍、教务处、医务室）
- **方向明确**：标注校门入口和北方向，帮助新生定位
- **季节特色**：加入校园的季节特色（樱花、银杏红叶、雪景等）增加美感
