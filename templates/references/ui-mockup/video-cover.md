# video-cover — 视频封面页

## 适用场景
YouTube/抖音/B站 等视频平台界面、视频播放页、视频列表缩略图。

## Prompt 结构
```
A video platform UI mockup, [screen type: video player / video feed / video grid], [layout: player area + title + engagement stats + related content], [color scheme], [style notes], [quality suffix], [aspect ratio]
```

## 注意事项
- **视频缩略图**：16:9 比例的预览图，是页面最大视觉元素
- **播放按钮**：半透明圆形播放图标，居中叠加在缩略图上
- **标题**：醒目的粗体文字，可包含话题标签
- **频道信息**：头像 + 频道名 + 订阅/关注按钮
- **互动数据**：播放量、点赞数、评论数、分享数
- **推荐内容**：侧栏或底部展示相关视频缩略图
- **平台风格差异**：YouTube 偏横屏桌面端，抖音/TikTok 偏竖屏移动端全屏
