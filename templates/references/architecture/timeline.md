# 时间线 — Timeline Infographic

## 适用场景
产品发展时间线、公司历史里程碑、项目进度规划、技术演进路线、版本发布历史。

## Prompt 结构
```
A clean and visually appealing timeline infographic showing {timeline topic} from {start year/event} to {end year/event}. The timeline runs {direction: horizontally left-to-right / vertically top-to-bottom} with a {line style: solid / dotted / gradient} central axis. {number} milestone points are marked along the timeline, each with a {marker type: circle / flag / icon} and a {content: label + short description + icon/image}. The color scheme uses {color description} with {accent style} for emphasis. Background is {background}. Modern infographic style, clean typography, suitable for presentations and reports. High quality, vector-like rendering, no watermark, no text artifacts.
```

```

Below the timeline, a subtle "Computing Power" growth curve (exponential line) runs parallel to the milestones. The overall design is clean and modern, with alternating labels above and below the axis to avoid crowding, flat icons, gradient accents, and generous whitespace. Vector quality, modern timeline infographic style, suitable for tech history presentations and educational materials, no watermark, no text artifacts.

## 注意事项
- 时间轴方向要明确（水平左到右或垂直上到下）
- 里程碑节点要有视觉标记（圆点、旗帜、图标）
- 节点标签包含时间 + 事件名称 + 简短描述
- 可以使用渐变色轴表示时间演进
- 交替布局（左右交替）避免拥挤
- 可以添加辅助信息（增长曲线、指标变化）
- 适合公司历史、产品路线、项目计划展示
- 输出分辨率建议 2048x1152（16:9）或 1152x2048（竖版）
