# Watercolor Illustration — 水彩插画

## 适用场景
- 绘本插画 / Children's book
- 文艺配图 / 诗歌配图
- 婚礼/请柬配图
- 心情日记配图
- 文艺品牌视觉

## Prompt 结构
```
[主体描述], watercolor illustration, soft washes, artistic watercolor painting, translucent layers, [色彩氛围], [纸张/笔触细节], --ar 16:9
```

## 质量后缀
```
watercolor illustration, soft washes, artistic watercolor painting, translucent layers, wet-on-wet technique, paper texture, delicate brushwork
```

## 注意事项
- 模拟水彩晕染效果，色块之间自然过渡
- 边缘要柔和，避免锐利线条
- 保留纸张纹理感
- 色彩饱和度偏低，以柔和的中间调为主
- 善用留白模拟水彩的自然空白
- 可加入水渍、颜料堆积等手工痕迹增强真实感
