# social-app — 社交 App

## 适用场景
微信/微博类社交应用界面、动态信息流、用户主页展示。

## Prompt 结构
```
A social media mobile app UI mockup, [screen type: feed / profile / chat list], [layout elements], [color scheme], [style notes], [quality suffix], [aspect ratio]
```

## 注意事项
- **信息流**：卡片式布局，头像 + 内容 + 互动按钮的标准三段式
- **头像**：圆形或圆角方形，统一尺寸，显示未读红点
- **互动按钮**：点赞、评论、转发、收藏，带数量显示
- **聊天入口**：底部 Tab 栏常驻导航，突出聊天功能
- **颜色**：根据平台风格选择——微信用绿色，微博用橙/蓝色
- **层级关系**：底部导航 > 内容区域 > 顶部操作栏
- **社交信号**：关注数、粉丝数、互动数据要显眼展示
