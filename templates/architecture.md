# 模板：架构图/技术插图

## 适用场景
用户要求生成论文插图、系统架构图、流程图、数据流图、方法管线图、技术架构图、网络拓扑图、微服务架构图等。

## 需求收集清单

| 字段 | 类型 | 必填 | 选项/说明 |
|------|------|------|----------|
| diagram_type | text | ✅ | 架构图/流程图/数据流/方法论/对比图 |
| sub_type | select | ✅ | 见下方子模板分类 |
| title | text | ❌ | 图表标题 |
| layers | text | ❌ | 架构层次描述 |
| components | text | ❌ | 关键组件名称 |
| style | select | ❌ | 扁平/3D/等距/手绘/学术风 |
| color_scheme | select | ❌ | 蓝紫科技/学术灰/企业绿/暖色 |
