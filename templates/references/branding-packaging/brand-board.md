# Brand Board — 品牌 VI 展示板

## 适用场景
品牌视觉识别系统展示、VI 规范手册、品牌提案演示、新品牌全案交付。用于一次性展示品牌的完整视觉体系。

## Prompt 结构
```
A professional brand identity board (VI board) for {brand/industry description}, displaying the complete visual identity system including {elements — primary logo/secondary logo/color palette/typography/brand patterns/icon set}. The board is organized in a {layout — clean grid/clean sections/modular sections} on a {background — white/light grey/brand color}. {Style notes — modern minimalist/warm organic/corporate professional}. Brand identity board, VI design presentation, brand guideline visual --ar 16:9
```

## 注意事项
- **系统完整**：VI 板应包含 Logo、色彩、字体、辅助图形/图案、应用示例五大模块
- **色值标注**：每个品牌色都要标注 HEX/RGB/CMYK 色值
- **层级清晰**：主 Logo、副 Logo、图标版要区分主次
- **应用展示**：至少 2-3 个实际应用场景（名片、包装、社媒等）让品牌落地
- **留白充足**：品牌板本身就是品牌形象的展示，排版要体现品牌调性
- **比例参考**：Logo 旁边要展示最小使用尺寸和周围安全空间
- **统一背景**：浅色背景展示浅色品牌，深色背景展示暗色品牌
- **导出尺寸**：建议 4K 或更高分辨率，确保文字清晰可读
