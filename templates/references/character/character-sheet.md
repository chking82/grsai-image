# 角色设定表

## 适用场景
游戏角色开发、动画角色设计、IP 形象规范、角色三视图参考。适合需要多角度展示角色设计的专业场景。

## Prompt 结构
```
A professional character design sheet of {character description}, presented as a reference layout for {use case — game development/animation/IP design}. The sheet includes {views — front view, side view, back view/three-view turnaround} of the same character at consistent scale and proportions. Each view shows {detail level — full body, expression close-ups, costume details}. {Color palette/reference swatches}. {Additional elements — expression grid, accessory callouts, scale comparison}. Clean white background, professional concept art layout. Character design sheet, three-view reference, character turnaround, concept art reference sheet.
```

## 示例

**用户输入：** IP 角色三视图，未来战士女性，银色机甲战衣，紫色能量纹路，正面/侧面/背面
**Prompt：**
```
A professional character design sheet of a futuristic female warrior in sleek armored combat gear, presented as a three-view turnaround reference layout for game character modeling. The sheet displays the character in front view (left), side profile view (center), and back view (right), all at consistent height and proportions against a clean white background grid. The character has athletic build with a toned physique, short asymmetrical silver hair with one shaved side, and sharp angular facial features with glowing purple eyes. She wears a form-fitting silver-grey armored suit with segmented plates on the chest, shoulders, forearms, and thighs, accented by bioluminescent purple energy circuit patterns that run along the armor seams and pulse faintly. The front view shows the full combat stance with a energy rifle held diagonally across the body, the side view reveals the armor plate layering and the character's profile with a small cybernetic implant behind the ear, and the back view displays the energy circuit continuation along the spine and the weapon holster on the right hip. Below the three views, a color palette reference shows the key colors: silver-grey (armor base), deep purple (energy accents), black (undersuit), and cyan (eye glow). Additional callout boxes highlight the helmet detail, the weapon design, and the energy circuit pattern. Clean technical illustration style with subtle shading, professional concept art layout. Character design sheet, three-view reference, character turnaround, concept art reference sheet.
```

## 注意事项
- 三视图必须保持比例一致——正面、侧面、背面的身高和各部位比例要对应
- 建议加辅助网格线或地平线，方便后续建模参考
- 表情特写是加分项——展示角色的情绪范围
- 色板/色卡是必要的——标注各部分颜色的具体色值
- 武器、配件的分解图对于游戏开发非常实用
- 背景必须是干净的（白色或浅灰），不能有干扰元素
- 输出分辨率建议 4096x2048 或更高（需要展示大量细节）
- 适合交付给 3D 建模师、动画师、其他设计师使用
