# 品牌吉祥物

## 适用场景
企业品牌 IP 形象设计、公司吉祥物、活动代言角色、周边产品主视觉。适合科技公司、互联网企业、消费品牌的吉祥物创作。

## Prompt 结构
```
A {animal/creature} mascot character for {brand/industry type}, designed with {personality trait} and {key visual feature}. The character {pose/expression} conveying {emotion/vibe}. Wearing/holding {brand-related element or accessory}. Clean, rounded character design optimized for {use case — logo, merchandise, digital}. {Color palette description} consistent with brand identity. Professional illustration on a {background style} background. Brand mascot design, cute character illustration, corporate mascot, friendly character design.
```

## 示例

### 示例 1
**用户输入：** 科技公司的猫吉祥物，蓝色系，戴 AR 眼镜，聪明活泼的感觉
**Prompt：**
```
A cat mascot character for a technology company, designed with an intelligent and playful personality, featuring oversized expressive eyes and a sleek, rounded body shape. The character is in a dynamic standing pose with one paw raised as if gesturing toward a floating holographic screen, conveying curiosity and tech-savviness. Wearing futuristic AR glasses with a subtle blue-tinted visor and a small glowing antenna earpiece. The fur is primarily white with electric blue gradient accents along the back, tail, and paw pads, consistent with a modern tech brand identity. Clean, rounded character design optimized for app icons, stickers, and merchandise. Set on a clean light grey radial gradient background with subtle circuit-board pattern elements. Brand mascot design, cute character illustration, corporate mascot, friendly character design.
```

### 示例 2
**用户输入：** 外卖平台的小熊吉祥物，橙色主色调，背着保温外卖箱，憨厚可爱
**Prompt：**
```
A bear mascot character for a food delivery platform, designed with a warm and approachable personality, featuring a chubby round body and a friendly smile with rosy cheeks. The character is in a cheerful walking pose carrying a bright orange insulated delivery backpack on its back, conveying reliability and speed. The delivery backpack has a subtle logo patch and a small steaming-food icon badge. The bear's fur is warm honey-brown with an orange t-shirt bearing a simplified delivery logo, consistent with the platform's vibrant orange brand identity. Clean, rounded character design optimized for mobile app splash screens, packaging, and plush merchandise. Set on a clean white background with a soft orange circular accent behind the character. Brand mascot design, cute character illustration, corporate mascot, friendly character design.
```

## 注意事项
- 吉祥物设计必须简洁、辨识度高，缩小到 logo 尺寸也能识别
- 颜色要与品牌色系一致，通常主色不超过 2-3 种
- 体型以圆润为主，避免尖锐棱角（给人亲和感）
- 表情是核心——眼睛要大且有神，嘴巴微笑
- 可以加入品牌相关道具（产品、logo 元素）增强识别
- 适合后续延展：表情包、周边、3D 化、动画化
- 输出分辨率建议 2048x2048
