# cartoon — 卡通头像

## 适用场景
社交头像、群头像、App 头像、扁平卡通风格。

## Prompt 结构
```
A flat design cartoon avatar of [subject description], [physical features], [attire], [pose and framing], [color scheme], clean geometric shapes, bold outlines, [quality suffix], [aspect ratio]
```

## 示例

## 质量后缀
```
flat design avatar, colorful cartoon style, clean character design, bold outlines, modern flat illustration
```

## 注意事项
- 简洁几何形状：圆形头部、简单曲线
- 明亮色彩，避免灰暗色调
- 可识别特征要突出（发型、眼镜等）
- 避免过度复杂的细节和纹理
- 圆形或圆角方形框架最适合做头像
- 大胆粗线条轮廓
