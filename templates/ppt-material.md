# 模板：PPT 背景/素材图

## 适用场景
用户要求生成 PPT 配图、幻灯片背景、过渡页背景、数据页配图、封面图、结尾页等。

## 需求收集清单

| 字段 | 类型 | 必填 | 选项/说明 |
|------|------|------|----------|
| usage | select | ✅ | 封面/过渡页/内容页背景/数据页配图/结尾页 |
| sub_type | select | ✅ | 见下方子模板类型 |
| theme | text | ✅ | 主题（科技/金融/教育/医疗等）|
| style | select | ❌ | 渐变/几何抽象/数据粒子/光效/极简 |
| color_scheme | text | ❌ | 配色方案 |
| text_area | boolean | ❌ | 是否需要预留文字区域（默认是）|

## 子模板类型（references/ppt-material/）

| 子模板 | 文件 | 关键词 | 示例场景 |
|--------|------|--------|---------|
| 封面背景 | `cover.md` | 封面、标题、大气 | PPT 首页、报告封面 |
| 过渡页背景 | `transition.md` | 过渡、章节、分隔 | 章节切换、段落过渡 |
| 内容页背景 | `content.md` | 内容、正文、柔和 | 文字内容页背景 |
| 数据页背景 | `data.md` | 数据、图表、专业 | 数据展示页、报表 |
| 科技风背景 | `tech.md` | 科技、粒子、网络 | 技术汇报、产品发布 |
| 金融风背景 | `finance.md` | 金融、专业、稳重 | 商业计划、财务报告 |
| 结尾页背景 | `ending.md` | 结尾、感谢、致谢 | Q&A 页、Thank You |

## 推荐参数

- model: gpt-image-2-vip
- imageSize: 3840x2160（4K 16:9）
